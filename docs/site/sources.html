Where they disagree with the code

DocumentSaysThe code
README.mdNothing touches the disk without FileIdentity.verify.Trash and folder rescan run the check. Reveal in Finder, Open and a full rescan don't.
CONTRIBUTING.mdAnything that touches the disk must go through FileIdentity.verify.The same three actions don't.
README.mdBig folders get name tags.Top-level files get them too, if the tile is big enough.
README.mdDrop a folder onto the window.The drop handler also accepts a file.
README.mdThe Scripts/ list names three scripts.There are four, and the list leaves out package-release.sh.
README.mdThe shortcut table lists the main actions.It leaves out ⇧⌘H for the home folder and ⇧⌘D for Macintosh HD.
README.mdTests run against real files in a temporary folder.Seven of the ten tests do. The other three use nodes or render jobs in memory.
Commit bbe1e3bKeep previous results when a rescan can't read the folder.A folder rescan keeps them. A full rescan doesn't, as listed in Open questions.

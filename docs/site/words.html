Words we use

Each of these words has one meaning, and most match a name in the code or the app's window.

The window

WordMeaningIn the code
The TreeThe panel that lists folders and files in sortable columns.DirectoryOutline
File TypesThe panel that lists extensions by total size.ExtensionList
The MapThe panel that draws the treemap, where a tile's area follows a node's size.TreemapCanvas
panelOne of the three areas in the ready window: The Tree, File Types or The Map.MainView
viewA SwiftUI or AppKit object that draws part of the window. Each panel is one, and so is the scanning screen.ScanningView
phaseWhich screen the window shows: welcome, scanning or ready.Phase
selectionThe one node that is marked in The Tree and The Map.selection
view rootThe node that fills The Map. Zooming changes it.viewRoot
styleHow The Map is drawn: Sketchbook or Cushions.TreemapStyle
themeThe window's colors: Ivory, Oat, Clay or Slate. The menu bar calls this menu Paper.Theme
toastA short message at the bottom of the window that clears after 3.2 seconds.showToast

The tree and its numbers

WordMeaningIn the code
scanOne run of the scanner over a folder. The app's menus call this mapping.DiskScanner
treeAll the nodes from one scan, held in memory.root
nodeOne file, folder or symlink in the tree.FileNode
rootThe top node of the tree. Its name is the full path of the scanned folder.root
sizeBytes allocated on disk. A folder's size is the total for everything below it.size
logical sizeA file's length in bytes, which can differ from its allocation.logicalSize
extensionThe lowercase text after a file name's last dot, from 1 to 12 bytes long. A name that starts with its only dot has none.extID
unreadableA folder the scanner couldn't list. It stays in the tree with a lock icon.unreadable
ownerThe one link in a hard-link group whose size holds the file's allocation. Every other link in the group has size 0.HardLinkRegistry

Drawing The Map

WordMeaningIn the code
tileA rectangle on The Map as the user sees it.rect
layoutThe rectangles computed for one view root at one window size.TreemapLayout
itemA rectangle in the layout that belongs to one node. Clicks resolve to items.Item
leafA rectangle in the layout that the renderer shades with one color.Leaf
lumpA gray leaf that stands for all the children too small to draw one by one.directoryLeaf
render jobThe plain values the renderer needs, with no node references.TreemapRenderJob
render tokenA flag shared with the renderer that stops work on an outdated picture.RenderToken

Changing the tree

WordMeaningIn the code
identity checkThe test that a node's path still leads to the object the scanner saw.FileIdentity.verify
full rescanA new scan of the root path that replaces the whole tree.rescan()
folder rescanA scan of one folder whose result replaces that folder's node. The menu item is Rescan This Folder.rescan(_:)
spliceThe step that puts a folder rescan's result into the tree.TreeEdit.splice
reconcileThe step that gives each hard-link group one owner after an edit.reconcile
generationA counter that goes up with each finished full scan and each closed map. A folder rescan from an older generation is dropped.scanGeneration
